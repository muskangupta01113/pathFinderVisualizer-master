# pathFinderVisualizer-master

An interactive web application that visualizes pathfinding algorithms using an animated grid. It helps users understand how different algorithms explore nodes and find paths between a starting point and a destination.

## 🚀 Features

- Visualizes **Dijkstra’s Algorithm, A*, Breadth-First Search (BFS), and Depth-First Search (DFS)**.
- Interactive grid for selecting start and end nodes.
- Create obstacles to simulate different pathfinding scenarios.
- Animated visualization of node exploration and path discovery.
- Helps compare graph traversal and pathfinding strategies.

## 🛠️ Technologies Used

- **HTML5** – Web page structure
- **CSS3** – Styling and grid layout
- **JavaScript** – Algorithm implementation and interactive functionality

## 💻 How to Run Locally

1. Clone this repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project folder in VS Code.
3. Open `index.html` in your browser, or use the **Live Server** extension.
4. Select an algorithm and explore the visualization.
